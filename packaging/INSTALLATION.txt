Dashboard - installation package contents

This DMG contains:
- Dashboard.app
- Chrome-Extension/
- Connections/connections-config.extension.txt
- Connections/connections-config.template.txt
- Applications shortcut

Install the macOS app:
1. Drag Dashboard.app to Applications.
2. If macOS blocks first launch, run:
   xattr -cr /Applications/Dashboard.app

Install the Chrome extension:
1. Open Chrome and go to chrome://extensions
2. Enable Developer mode
3. Click "Load unpacked"
4. Select the Chrome-Extension folder copied from this DMG

Import the app connections template:
1. Open the macOS app
2. Go to Settings
3. In "Import / Export connections", click "Import file"
4. Choose Connections/connections-config.extension.txt to import the extension-aligned values
5. Or choose Connections/connections-config.template.txt for a blank starter file
6. Fill in your real tokens, IDs, API keys, calendar URLs, and mappings

Security note:
- Chrome-Extension/config.js and the connections template can contain sensitive values.
- Do not distribute a filled package unless you intend to share those secrets.
